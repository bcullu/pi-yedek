Privacy policy

pi-yedek is used only by its owner, to back up the owner's own data to the owner's own Google Drive account.

  • It requests only the drive.file scope, so it can access only files it has created itself.
  • Data is encrypted on the owner's own computer before upload. Google and any third party see only encrypted data.
  • Access tokens are stored only on the owner's own computer. No data is sent to, shared with, or sold to anyone else.
  • No analytics, advertising or tracking is used.

Questions: open an issue in the GitHub repository.
